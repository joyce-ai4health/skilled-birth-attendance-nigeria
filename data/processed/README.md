# Processed Data

This folder is reserved for datasets that have been fully cleaned, transformed, and prepared for analysis and machine-learning modelling.

The original DHS datasets will not be stored in this repository because the DHS Program data are restricted and must not be redistributed.

Processed DHS datasets containing respondent-level data will also not be uploaded to this public repository.

Reproducible scripts and notebooks used to create the processed analytical dataset will be provided in the repository.
