# Raw Data

This folder is reserved for the original 2023–24 Nigeria Demographic and Health Survey (NDHS) datasets used in this research.

The raw datasets were obtained from The DHS Program after authorization was granted for this research project.

## Data Usage

The original DHS datasets are not included in this public GitHub repository because access to the data is subject to The DHS Program's terms of use.

Authorized users can request access directly from The DHS Program.

## Important

Raw data files stored locally in this folder should not be modified. Any cleaned or transformed datasets created during the research will be stored separately in the appropriate data folders.
