# Interim Data

This folder is reserved for intermediate datasets created during the preparation of the 2023–24 Nigeria Demographic and Health Survey (NDHS) data.

Examples may include data produced after:

- selecting the eligible study population
- selecting relevant variables
- recoding variables
- handling missing values
- creating the skilled birth attendance outcome variable
- combining information from relevant DHS files, if required

These files represent working versions of the data and are not the final datasets used for modelling.

Because the source data are obtained from The DHS Program under authorized access, intermediate respondent-level datasets will not be uploaded to this public GitHub repository.
