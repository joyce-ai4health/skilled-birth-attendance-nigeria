# Models

This folder is reserved for trained machine-learning models and related model documentation produced during the research.

Potential models include:

- Logistic Regression
- Decision Tree
- Random Forest
- Gradient Boosting

Only final or important model artifacts will be retained.

## Model Documentation

For selected models, the project will document:

- Model type
- Features used
- Hyperparameters
- Training approach
- Validation method
- Evaluation results
- Random seed
- Software/package version

Model files that contain restricted DHS respondent-level information or create a risk of exposing restricted data will not be published in this repository.

The final decision on which model artifacts can be shared will follow the DHS Program data-use requirements.
