# Source Code

This folder contains reusable Python scripts and functions developed for the research project.

As the project progresses, code may be organised into modules for:

- Data loading and preparation
- Data cleaning
- Feature engineering
- Statistical analysis
- Machine-learning modelling
- Model evaluation
- Model explainability
- Utility functions

Keeping reusable code in this folder will help make the analysis organised, reproducible, and easier to maintain.

Restricted DHS data will not be stored in this folder or uploaded to the public repository.
