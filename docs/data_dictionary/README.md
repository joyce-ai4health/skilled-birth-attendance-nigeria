# Data Dictionary

This folder contains documentation for the variables selected from the 2023–24 Nigeria Demographic and Health Survey (NDHS).

The project data dictionary will document:

- DHS variable name/code
- Variable description
- Source DHS file
- Original categories or values
- Role in the research (outcome or predictor)
- Recoding or transformation performed
- Missing or special values
- Final variable name used in the analysis
- Reason for including the variable

## Outcome Variable

The main outcome of the research is skilled birth attendance.

The exact DHS variables and coding required to construct the outcome will be confirmed from the official 2023–24 NDHS documentation before analysis.

## Predictor Variables

Potential predictors will be selected based on:

- Availability before delivery
- Relevance to the research questions
- Evidence from previous literature
- Availability in the 2023–24 NDHS
- Missing-data considerations

The final data dictionary will be developed during the data audit stage.
