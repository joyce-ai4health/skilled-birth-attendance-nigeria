# Methodology

This folder contains documentation for the research methodology used in the project.

The methodology will be developed according to the internship Research Guide and will cover the following areas:

## 6.1 Research Design

- Research design and approach
- Statistical and machine-learning components
- Overall experimental workflow

## 6.2 Data

- 2023–24 Nigeria Demographic and Health Survey (NDHS)
- Data source and access
- Study population
- Inclusion and exclusion criteria
- Outcome variable
- Predictor variables
- Data privacy and usage requirements

## 6.3 Preprocessing and Feature Engineering

- Variable selection
- Missing-value handling
- Variable recoding
- Categorical-variable encoding
- Numerical-variable preparation
- Class imbalance assessment
- Feature engineering where appropriate
- Prevention of data leakage

## 6.4 Models

Candidate models may include:

- Logistic Regression
- Decision Tree
- Random Forest
- Gradient Boosting

The final models will be determined during methodology development and supported by the literature review.

## 6.5 Validation and Experimental Protocol

The research will document:

- Train/validation/test strategy
- Cross-validation
- Hyperparameter tuning
- Geographic or region-based validation where appropriate
- Baseline comparisons

## 6.6 Evaluation Metrics

Potential classification metrics include:

- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC
- PR-AUC
- Confusion matrix
- Calibration measures

The final metrics will be selected based on the research objective and characteristics of the outcome.

## 6.7 Reproducibility and Code Release

The project will document:

- Software and package versions
- Random seeds
- Reproducible preprocessing
- Model configuration
- Public analysis code
- Instructions for obtaining the restricted DHS data

Restricted DHS respondent-level data will not be published in this repository.
