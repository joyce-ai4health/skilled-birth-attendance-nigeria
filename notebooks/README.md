# Notebooks

This folder contains the Jupyter notebooks used throughout the research project.

The analysis will be organised into separate notebooks so that each stage of the research can be followed clearly and reproduced.

Planned notebooks:

1. `01_data_audit.ipynb` — inspect the DHS datasets, variables, sample size and missing values.
2. `02_data_cleaning.ipynb` — clean and prepare the selected variables.
3. `03_exploratory_analysis.ipynb` — explore the study population, outcome and predictor variables.
4. `04_feature_engineering.ipynb` — prepare features for modelling.
5. `05_statistical_analysis.ipynb` — conduct descriptive and association analyses.
6. `06_modeling.ipynb` — develop the machine-learning models.
7. `07_model_evaluation.ipynb` — compare model performance and calibration.
8. `08_explainability.ipynb` — interpret model predictions and important features.
9. `09_subgroup_analysis.ipynb` — assess performance across geographical and socioeconomic groups.

The notebooks will not contain or redistribute restricted DHS respondent-level data.
