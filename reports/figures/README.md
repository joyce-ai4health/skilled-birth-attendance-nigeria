# Figures

This folder contains figures and visualisations generated during the research.

Examples may include:

- Skilled birth attendance distribution
- Geographic and socioeconomic comparisons
- Exploratory data visualisations
- Model comparison charts
- ROC curves
- Precision-Recall curves
- Calibration plots
- Confusion matrices
- Feature importance or SHAP plots
- Subgroup performance visualisations

Figures selected for the final research paper will be generated reproducibly from the project's analysis code.

No restricted DHS respondent-level data will be included in published figures.
