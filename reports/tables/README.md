# Tables

This folder contains tables generated during the research analysis.

Examples may include:

- Study population characteristics
- Skilled birth attendance distribution
- Missing-data summaries
- Descriptive statistics
- Logistic regression results
- Model performance comparisons
- Hyperparameter tuning results
- Subgroup performance results
- Calibration results

Tables selected for the final research paper will be generated reproducibly from the analysis code.

No restricted DHS respondent-level data will be included in published tables.
